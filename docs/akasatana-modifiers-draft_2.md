# あかさたなみだくじ 修飾語リスト（叩き台 v2）

全4カテゴリ × 30語 = 120語

**選定基準**

- 声色・話し方で表現できるか（音声プラットフォーム前提）
- お題であってオチではない（DJが足せる余地を残す）
- 人格ではなく状況を貶める
- 接続語まで含めた完成形で記載（プログラム側で助詞を付与しない）
- **言われた瞬間で完結せず、その先の5文字を喋る手がかりが残るか**

表記はすべて「〇〇 + ユーザ名 + の + 行」で成立する形にしてある。

**カテゴリの軸**

|                                | 内容                       | カテゴリ            |
| ------------------------------ | -------------------------- | ------------------- |
| **どう喋るか**（演技の指示）   | 声・人格を変える           | 声色系 / キャラ変系 |
| **どんな状況か**（状況の指示） | 立たされている場面を与える | エモ系 / ダメ人間系 |

状況カテゴリは、しんみり側（エモ系）と笑い側（ダメ人間系）で対になっている。
